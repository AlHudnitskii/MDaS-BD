# Интернет-магазин

Полнофункциональный интернет-магазин с реляционной и NoSQL базами данных  
Лабораторные работы по курсу «Модели данных и СУБД»

Студент: Худницкий А.В. Группа: 353502

## Функциональность

### Авторизация
- Регистрация, вход, выход
- JWT-токены с Redis blacklist
- Блокировка после 3 неудачных попыток на 10 минут

### Каталог
- Просмотр товаров с фильтрацией по категории и сортировкой
- Поиск по названию
- Скидки на товары

### Личный кабинет
- Редактирование профиля и аватара
- История заказов
- Личные заметки, отзывы, списки желаемого

## NoSQL

### Redis DB0 -- Кэш и JWT Blacklist
Cache-aside паттерн для товаров, категорий, пользователей и статистики. Инвалидация по префиксу через `SCAN`. При 3 неудачных попытках входа - аккаунт блокируется через blacklist (TTL 10 мин).

### Redis DB1 -- Сессии
Хранение сессий вместо памяти приложения. Sliding expiration. Несколько инстансов приложения автоматически видят одни и те же сессии через общий Redis.

### Redis DB2 -- Pub/Sub
Синхронизация состояния между инстансами через три канала:

| Канал | Событие | Реакция |
|-------|---------|---------|
| `shop:cache:invalidate` | Изменение данных | Инвалидация кэша |
| `shop:user:events` | Логаут / обновление профиля | Удаление сессии |
| `shop:order:events` | Оплата заказа | Сброс кэша статистики |

Фоновый `Subscriber`-поток слушает каналы и реагирует автоматически.

### MongoDB — Логирование и аналитика
Коллекции `action_logs` и `error_logs` с TTL-индексами (90 и 30 дней). Агрегационные отчёты:

- Активность по периодам (день / неделя / месяц)
- Топ-10 активных пользователей
- Распределение операций (CRUD)
- Почасовые тренды за 14 дней
- Обнаружение аномалий (брутфорс, аномальная нагрузка)

## Структура проекта

```
internet-shop/
├── shop/
│   ├── core/            # Подключения: postgres, redis, mongo, pubsub
│   ├── cache/           # CacheService, CacheKeys
│   ├── auth/            # JWT, middleware, сессии
│   ├── middleware/      # SessionAuth, Cart
│   ├── repositories/    # SQL + mongo_log, mongo_analytics

│   └── views/           # HTTP handlers + analytics dashboard

├── static/
├── docker-compose.yml   # Redis + Redis Commander
```

## Запуск проекта

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Поднять Redis
docker-compose up -d

# 3. Запустить сервер
python manage.py runserver
```
